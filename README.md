# campus-shortest-route-finder
A menu-driven C project to find the shortest campus routes using Dijkstra's algorithm.

## About the Project
Campus Shortest Route Finder is a menu-driven project developed using the C programming language. It uses Dijkstra's algorithm to find the shortest distance between campus locations.

## Features
- Add campus locations and roads.
- Display the adjacency matrix.
- Select a source location.
- Calculate shortest distances using Dijkstra's algorithm.
- Display the shortest path to each reachable location.
- Display distances from the source to all locations.

## Technologies Used
- C Programming
- Graph Theory
- Dijkstra's Algorithm
- Adjacency Matrix

## How to Run
1. Clone or download this repository.
2. Open the project in a C compiler, such as GCC or Code::Blocks.
3. Compile the program:

   ```bash
   gcc campus_shortest_route.c -o campus_shortest_route
   ```

4. Run the program:

   ```bash
   ./campus_shortest_route
   ```

   On Windows, run:

   ```bash
   campus_shortest_route.exe
   ```

## Menu Options
1. Add Campus Graph
2. Display Matrix
3. Select Source
4. Find Shortest Distance
5. Display Shortest Paths
6. Display All Distances
7. Exit

## Learning Outcomes
- Understand graph representation using an adjacency matrix.
- Implement Dijkstra's shortest-path algorithm in C.
- Work with arrays, functions, loops, and conditional statements.
- Apply graph algorithms to a practical campus navigation problem.
